# Contexto

`tl_construction_bc3` es un módulo de **Odoo 20** de Tecniloop.

- Dependencias declaradas: `construction_developer` y `sale_management`.
- Compatibilidad opcional con `tl_construction_certification`, necesario para crear certificaciones desde BC3 tipo 3.
- No se instala Odoo desde este paquete y no se ha probado una base Odoo 20 Enterprise en el entorno de desarrollo.
- El importador gestiona un subconjunto de FIEBDC-3/2024, no sustituye un programa de mediciones ni un validador integral de BC3.
