Para añadir cuentas bancarias a compañías, clientes o proveedores, utilice las cuentas
bancarias (`res.partner.bank`) de Odoo 20.

Para definir el patrón del nombre mostrado en empresas, vaya a Configuración > Técnico >
Parámetros > Parámetros del sistema y edite la clave `l10n_es_partner.name_pattern`.
Puede utilizar `%(name)s` para el nombre y `%(comercial_name)s` para el nombre comercial.
